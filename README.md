# aayush.world

Personal website for Aayush Kucheria — [aayush.world](https://aayush.world)

Built with [Astro](https://astro.build). The custom domain is managed through Railway; DNS points to GitHub Pages, where GitHub Actions deploys the site.

## Project layout

- `src/pages/index.astro` is the current site's source.
- `public/pics/` holds the photos used by the current page.
- `public/archive/2026-09-25/` is a self-contained snapshot of the older site, including its own images, styles, and script. Keep those files together so the archived URL continues to work.
- `public/CNAME` and the favicons are copied to the site root.
- `dist/` is generated by `npm run build`: Astro copies `public/` into it and builds the current page there. It is ignored by Git and is not another source tree.
