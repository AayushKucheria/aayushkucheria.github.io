# aayush.world

Personal website for Aayush Kucheria — [aayush.world](https://aayush.world)

Built with [Astro](https://astro.build). The custom domain is managed through Railway; DNS points to GitHub Pages, where GitHub Actions deploys the site.

## Saved version

[View the website as saved on 25 September 2026](https://aayush.world/archive/2026-09-25/). Its source is preserved on the [`archive/site-2026-09-25` branch](https://github.com/AayushKucheria/aayushkucheria.github.io/tree/archive/site-2026-09-25).

## Dev

```sh
npm install
npm run dev      # localhost:4321
npm run build    # builds to ./dist
npm test         # splash regression tests (build + preview on 4322)
```
